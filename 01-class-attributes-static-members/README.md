# 📦 Class, Attributes, and Static Members

This module covers the foundation of Object-Oriented Programming (OOP) in Java, focusing on how to represent real-world entities through code.

### Concepts Practiced:
* **Classes and Attributes:** Defining the structure and data of objects (e.g., Retangle, Employee).
* **Methods:** Implementing object behavior and delegating logic to the appropriate entities.
* **Static Members:** Understanding the `static` keyword for utility methods and constants that belong to the class rather than a specific instance.

### Featured Exercise:
2. **Currency Converter:** Using static members to calculate currency exchange including tax (IOF).
