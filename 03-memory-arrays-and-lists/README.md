# 🧠 Memory Management, Arrays, and Lists

Focuses on how Java manages data in memory and how to work with collections of data.

### Concepts Practiced:
* **Memory Allocation:** Understanding the difference between **Stack** (local variables) and **Heap** (objects/arrays).
* **Reference vs. Value Types:** How Java handles primitive types versus object references.
* **Arrays:** Managing fixed-size data structures for both primitives and objects.
* **Lists (ArrayList):** Implementing dynamic collections, using interfaces, and performing search operations.
* **Matrices:** Navigating 2D arrays and implementing neighbor-check logic.
* **Boxing/Unboxing:** Utilizing Wrapper Classes (`Integer`, `Double`) for collections.

### Featured Exercises:
1. **Boarding House:** Managing room rentals using an array of objects with null-check logic.
2. **Employee Management:** Using `List` for registration, searching by ID, and applying salary increases.
3. **Matrix Challenge:** Analyzing a 2D grid to find specific values and their neighboring elements.
